## Organisation

Chaque partie du cours a son propre dossier, et chaque application a son propre sous-dossier :

```
fullstackopen/
├── part0/            # Diagrammes de séquence (Markdown + Mermaid)
├── part1/

│   ├── unicafe/
│   └── anecdotes/

│   ├── phonebook/

```
